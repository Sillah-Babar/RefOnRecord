## Meeting 3.
* **DATE:**
* **PARTICIPANTS: Sillah Babar, Faisal Khan, Fajr Naveed**
* **TEACHER:**

### Action points
* Stateless API — No server-side session storage between requests. Each request must carry all necessary context.
* Cyclic Imports — Audit and fix circular import chains. Refactor shared dependencies into a separate module to break cycles.
* Machine-to-Machine (M2M) Auth — Implement M2M authentication for the verification request flow.
* 201 Created + Location Header — On successful resource creation, return 201 Created with the Location header pointing to the new resource URL.
* Reverse URLs — Use url_for() instead of hardcoded URL strings for better maintainability and safer refactoring.
* Cache Decorators — Apply cache decorators on heavy read endpoints. Use permanent, stable keys based on resource identifiers — not auto-generated ones. Invalidate on mutation.
* Database inside Resume Verifier — The database should live within the Resume Verifier service. Other services must access resume data only through its API, never via direct DB access.
